## Page Structure Overview

### Main Pages
- **index.html** - Homepage with bio, experience timeline
- **about.html** - Detailed about page with achievements
- **projects.html** - Projects showcase (16 projects)
- **all-projects.html** - Complete projects listing
- **contact.html** - Contact form and information
- **expertise.html** - Skills and expertise showcase
- **pricing.html** - Services and pricing information
- **mysaas.html** - SaaS platforms overview
- **saas.html** - Individual SaaS platform details
- **quote.html** - Quote request form
- **qouteviewer.html** - Quote viewing interface
- **login.html** - Client portal login
- **viewrentals.html** - Rental viewing page
- **404.html** - Error page

### Components
- **navbar.js** - Reusable navigation header component
- **footer.js** - Reusable footer component
- **whatsapp-button.js** - Floating WhatsApp button component

### Assets
- **assests/** - Contains all images, logos, and media files
  - Profile images (_DSC*.JPG)
  - Project logos and screenshots
  - Icons and branding assets

### Styling
- **css/** - Modular CSS files for each page/section
- **styles/** - Additional style files

### Scripts
- **js/** - JavaScript utilities and animations
- Root level JS files for components and functionality
